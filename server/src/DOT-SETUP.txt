현재 권장 연결 방식: Phone Connect 서버는 사용자 로컬 PC의 Podman 단일 컨테이너에서 실행하고 Dot은 외부 HTTPS로 조회한다.

서버 설치는 저장소의 server/container/README.md를 따른다. 컨테이너를 시작하면 서버·웹·수신/조회 터널·음성 전사가 자동으로 실행된다. PC의 실제 폴더를 /data에 바인드 마운트한다.

Dot의 명령 실행 샌드박스에 이 서버를 설치하지 않는다. PC 웹의 연결 화면에서 받은 dot-reader.json과 저장소의 dot/client.py, dot/SETUP.txt를 사용한다. 실제 조회 성공 전 연결 완료라고 보고하지 않는다.
