ChatGPT · Dot MCP 연결

문자·카카오톡·통화 전사를 ChatGPT가 조회하도록 연결합니다. Python 파일을 전달하지 않습니다.

1. 서버와 로그인 계정 설정

OAuth 제공자에서 본인의 로그인 계정과 API를 준비한 뒤 아래 값을 입력하세요. 비밀번호나 Client Secret은 여기에 입력하지 않습니다.

계속 사용하려면 고정 주소를 사용하세요. 임시 주소가 바뀌면 OAuth API 식별자와 ChatGPT 연결도 수정해야 합니다.

이 사용자 ID와 일치하는 계정에만 기록을 제공합니다. 이메일이나 OAuth Client ID가 아닙니다.

2. ChatGPT에서 연결

웹의 계정용 사용자 지정 MCP/플러그인 등록에서 다음 값을 사용하세요. 데스크톱 앱의 로컬 MCP 등록은 계정 전체 연결과 다릅니다.

이름: Phone Connect
MCP 주소: 설정 후 표시됩니다.
인증: OAuth
API 식별자 / Audience:
조회 권한: records:read

로그인 제공자에서 PKCE S256과 resource 매개변수 처리가 필요합니다. ChatGPT가 표시하는 정확한 OAuth 콜백 주소를 등록하세요.

설정 및 검증 안내

설정 저장은 연결 성공을 뜻하지 않습니다. ChatGPT에서 인증 후 상태·테스트 기록 조회를 확인해야 합니다. 녹음은 전사 텍스트로 조회하며 원본 음성 스트리밍은 제공하지 않습니다.
